# create_poke_clips

Thin wrapper around :mod:`delphi_data.video_processing`.

All logic lives in the package module.  See the
[video_processing API page](../api/video_processing.md) for the full reference.

!!! note "System requirements"
    `ffmpeg` and `ffprobe` must be on `PATH`.

!!! note "Python requirements"
    ```bash
    pip install delphi-data[video]
    ```
