
# delphi-data

A Python toolkit for data ingestion, curation, computing behavior measures, and visualization built on the Aeon API.

## Overview

`delphi-data` provides a standardized framework for:

- Data ingestion (Harp registers, CSV, video)
- Data curation (cleaning, validation, standard data ouput structure)
- Data quality control (valve control, frame rate, unit tests)
- Poke metrics (Poke rate, poke duration)
- Visualization (plots, video overlays)

This package is designed to integrate tightly with the [Aeon API](https://github.com/SainsburyWellcomeCentre/aeon_api).

## Installation and Deployment

### 1. Recommended - Install uv

We recommend using [uv](https://docs.astral.sh/uv/) for dependency and environment management.

### 2. Create virtual environment

uv sync --all-extras

Alternatively and not dependent on uv,

pip install -e .

## Development Documentation Practices
- Code should use a linter to ensure consistent code formatting and style. We recommend [ruff](https://docs.astral.sh/ruff/linter/)
- Each function requires a docstring that provides a brief description of the function, its arguments, and what is returned (if none, specify that). We use [mkdocstings](https://mkdocstrings.github.io/python/) to render API documentation from docstrings in python code.   

---

## Development Standard Practices
- Code should be developed in the users sandbox directory in the dev-sandbox branch. 
- Once code is vetted and properly documented, the developer should create a new GitHub branch and submit a pull request (PR), selecting Prattbuw (and optionally others) as a reviewer. Ambigeous lines of code that were generated by an AI agent must be highlighted in the description of the PR. 
- The developer must respond to any comments or requested edits in a timely manner. 
- The branch associated with the PR will be deleted after the new code elements are merged into the main branch.
